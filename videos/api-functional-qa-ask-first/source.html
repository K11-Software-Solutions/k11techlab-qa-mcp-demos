ERROR CONTRACT

"Cancelling an order that has already shipped is rejected"
DELETE SEMANTICS
Is the record removed (hard delete) or kept and marked (soft delete: which status or column)? And what does GET return for it afterwards?
ACCESS
What should happen without credentials, and when one user calls with another user's IDs: 401, 403 or 404?
SPEC MISMATCH
The story uses "refundAmount", but no parameter, request field or response field in the spec has that name. Which field does it mean?
